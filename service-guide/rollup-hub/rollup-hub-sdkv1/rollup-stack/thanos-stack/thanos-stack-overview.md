# Thanos Stack Overview

**The first available stack in SDKv1 for appchain deployment is the Thanos Stack**—an Optimistic Rollup based architecture that enables deployers to use <mark style="color:red;">**TON as the native gas token**</mark>.You can find detailed information about Thanos stack architecture and features [here](https://docs.tokamak.network/home/service-guide/tokamak-l2/thanos-stack).<br>

In future releases, we plan to expand SDK with additional stack options, including ZK Rollup-based solutions.
