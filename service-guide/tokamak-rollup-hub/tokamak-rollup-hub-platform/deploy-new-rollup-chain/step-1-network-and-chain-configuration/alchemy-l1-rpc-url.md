# Alchemy - L1 RPC URL

1. Create an account on [Alchemy](https://www.alchemy.com/) and sign in.
2. Once logged in, navigate to the _Endpoint_ tab located at the bottom-left corner of the dashboard.

![](<../../../../../.gitbook/assets/Screenshot 2025-12-05 at 2.51.49 PM.png>)

3. In the Endpoints tab, locate Ethereum and select “**Sepolia**.” Then, copy the provided URL.
