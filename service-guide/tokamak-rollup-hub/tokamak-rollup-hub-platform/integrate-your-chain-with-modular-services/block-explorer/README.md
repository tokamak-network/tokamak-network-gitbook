# Block Explorer

#### Typical Installation Time : 8 \~ 10 minutes

1. At first you need to meet the below pre-requisites before you begin the Block explorer installation.

&#x20; Prerequisites:

* [Coinmarketcap API](https://docs.tokamak.network/home/~/revisions/vZ6jfjMssAY5uH4RWtbr/service-guide/rollup-hub/rollup-hub-platform/integrate-your-chain-with-modular-services/block-explorer/coinmarket-api)
* [Reown ID (Previously WalletConnect)](https://docs.tokamak.network/home/~/revisions/YH9KHZa21xWmjYyTbJRF/service-guide/tokamak-rollup-hub/tokamak-rollup-hub-platform/integrate-your-chain-with-modular-services/block-explorer/reown-id-previously-walletconnect)

2. Now, click on integrations tab and check the available component types

<figure><img src="../../../../../.gitbook/assets/Screenshot 2025-12-08 at 2.29.39 PM.png" alt=""><figcaption></figcaption></figure>

3. Click on “ + ” icon on the block explorer component and input the parameters. See Database Username and Password's naming convention [here](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_Limits.html#RDS_Limits.Constraints).

<figure><img src="../../../../../.gitbook/assets/Screenshot 2025-12-08 at 2.29.57 PM.png" alt=""><figcaption></figcaption></figure>

4. Click on continue and confirm installation
5. You can now check the Block Explorer Installation in the deployment history tab

<figure><img src="../../../../../.gitbook/assets/Screenshot 2025-12-08 at 2.30.12 PM.png" alt=""><figcaption></figcaption></figure>

6. Check confirmation to ensure block explorer installed successfully

<figure><img src="../../../../../.gitbook/assets/Screenshot 2025-12-08 at 2.30.30 PM.png" alt=""><figcaption></figcaption></figure>

#### Uninstallation

The operator can uninstall the explorer by clicking the bin icon and confirming the action.
