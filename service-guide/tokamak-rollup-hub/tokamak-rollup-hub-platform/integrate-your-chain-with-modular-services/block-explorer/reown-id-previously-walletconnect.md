# Reown ID (Previously WalletConnect)

**This guide explains how to obtain the Reown/WalletConnect Project ID.**

* Reference: [docs](https://docs.blockscout.com/setup/configuration-options/walletconnect-project-id-for-contract-read-write#setting-up-a-reown-project-id)
* After logging in to reown, click on _Create Project_.
* Copy the Project ID from there at top right and use it in the platform
