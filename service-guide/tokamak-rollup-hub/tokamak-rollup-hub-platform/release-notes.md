# Release Notes

Date: **December 17, 2025**

This page outlines the latest updates, features, and improvements across the Tokamak Network ecosystem components.

#### 1. Tokamak Rollup Hub Platform

Version: [`v1.0.0`](https://github.com/tokamak-network/trh-platform/releases/tag/v1.0.0) | [Repository](https://github.com/tokamak-network/trh-platform/tree/v1.0.0)

This repository orchestrates the underlying infrastructure and containerized services required to run the rollup ecosystem efficiently.

Latest Changes: Infrastructure updates for the underlying platform orchestration.

#### 2. Tokamak Rollup Hub Platform Frontend

Version: [`v1.0.0`](https://github.com/tokamak-network/trh-platform-ui/releases/tag/v1.0.0) | [Repository](https://github.com/tokamak-network/trh-platform-ui/tree/v1.0.0)

The Platform UI provides a visual interface for users to deploy, configure, and manage their rollup networks without interacting directly with the command line.

Latest changes: The initial major release of the Platform UI focuses on rollup management interfaces and configuration workflows.

#### 3. Tokamak Rollup Hub Platform Backend

Version: [`v1.0.1a`](https://github.com/tokamak-network/trh-backend/releases/tag/v1.0.1a) | [Repository](https://github.com/tokamak-network/trh-backend/tree/v1.0.1a)

The Backend serves as the central logic layer for the Hub, handling API requests, deployment coordination, and integration with external services.

Latest Changes: This major release introduces core functionalities for deployment management, plugin integrations, and system monitoring.

#### 4. Thanos Stack

Version: [`v2.0.0`](https://github.com/tokamak-network/tokamak-thanos/releases/tag/release-2.0.0) | [Core Repository](https://github.com/tokamak-network/tokamak-thanos/tree/release-2.0.0)

Tokamak Thanos is the core Layer 2 protocol implementation, modified to support the specific scalability and security requirements of the Tokamak Network.

Latest Changes: A major update for the Thanos layer 2 stack, introducing the Fusaka hardfork support and enhanced verification tools.

Version: [`v1.0.6`](https://github.com/tokamak-network/tokamak-thanos-stack/releases/tag/thanos-stack-1.0.6) | [Infra Repository](https://github.com/tokamak-network/tokamak-thanos-stack/tree/thanos-stack-1.0.6)

This project contains the Helm charts and deployment configurations necessary to launch essential components of the Thanos stack.

Latest Changes: Updates to the Helm charts for deploying essential stack components.

#### 5. Tokamak Rollup Hub SDK

Version: [`v1.0.3`](https://github.com/tokamak-network/trh-sdk/releases/tag/v1.0.3) | [Repository](https://github.com/tokamak-network/trh-sdk/tree/v1.0.3)

The SDK provides developers and systems with the necessary tools and libraries to interact programmatically with the Tokamak Rollup Hub.

Latest Changes: A maintenance release focused on ensuring compatibility and stability across the deployment ecosystem.
